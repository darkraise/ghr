What makes it graphical

  • Last-hour recorder: each runner slot is a lane, each job a bar coloured by result, the running bar grows toward "now". Waiting jobs and CPU share the time axis, so a queue spike lines up with the slots that were full.
  • 24-hour strip per repository: one cell per hour, darker for more runs, red for any failure, the current hour outlined.
  • Disk drawn by what fills it, with the prune line marked.
  • Capacity cells per repository and the capacity rail in the sidebar.

Where the data comes from

  • 1h and 3h draw one lane per slot from history (start, end and result of each job) and live runners. Jobs are packed into lanes in the browser, since history doesn't record the slot.
  • 24h, 7d and 30d switch to buckets (hour, 6 hours, day): busy slot time and runs come from history, which ghr keeps for 30 days by default.
  • Waiting and CPU beyond the last hour need new storage: ghr keeps only 60 one-minute samples today. Keeping 3 hours of minutes plus hourly rollups for 30 days is about 900 small records.
  • 24-hour strip: history, grouped by hour.
  • Disk breakdown: the existing Storage response (Docker rows, toolchains, package caches). The 240 GB total needs one new field.
  • API budget shows the current count only; ghr keeps no history of it.

What the rules changed

  • Violet dropped: all three rule sets name purple as the most common AI fingerprint.
  • Colour moved into the shell: a petrol (or cobalt) sidebar, a tinted ground, and one accent for actions, selection and "running".
  • No nested boxes. The sheet and the panel cards are gone; only the runner slots, the live element, sit on a surface.
  • Status dots only where they carry live state (runner slots). Repository state is a word; events get an icon only for success, failure and warnings.
  • No pills around plain text, no Unicode check marks as icons, no "·" chains, no dashes in empty cells, no uppercase mono labels.
  • Signature: the capacity rail in the sidebar, on every page. Filled is busy, outlined is warm, dim is free.

Rules the redesign adopts

  • One accent. Green, amber and red only for meaning, always with an icon or word as well.
  • Borders are the only elevation. No glow, glass, gradient text or coloured side borders.
  • Radius: controls 6px, surfaces 10px. Nothing pill-shaped except toggles.
  • Monospace only for numbers, times and IDs; tabular numerals everywhere.
  • Selection, focus rings and scrollbars themed from the palette.
  • Plain copy: buttons name their action, errors say what to do, no em-dashes.
  • One icon library (Tabler or Phosphor) in place of Lucide, the default AI pick.
